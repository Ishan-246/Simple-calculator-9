#  Simple Calculator App

A clean and responsive calculator built with **React JS**. It supports basic arithmetic operations and follows the standard BODMAS rule for accurate calculations.

---

##  Features

- Basic arithmetic operations: `+`, `-`, `*`, `/`
- Real-time input and display
- Handles errors gracefully
- Clean and minimal UI
